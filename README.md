# Roblox AFK

Roblox AFK is a lightweight Windows desktop utility that helps prevent Roblox from disconnecting you for inactivity. It is built with [Tauri 2](https://tauri.app/), Rust, HTML, Python, and AutoHotkey.

The application lets you configure a keyboard action—such as holding `W` or tapping a key—at a selected interval. It supports two automation modes:

- **AutoHotkey mode**: Activates the Roblox window and sends real keyboard input. Roblox must remain in the foreground while the worker is running.
- **Python / pywinauto mode**: Sends keyboard messages directly to the Roblox window by process ID, allowing the automation to work without keeping Roblox focused.

> **Important:** This project is intended for Windows because it relies on AutoHotkey, Windows process detection, and Windows window messages.

## Features

- Hold a key for a configurable duration.
- Tap a key one or more times per cycle.
- Configure the delay between actions.
- Support for common keys such as `W`, `A`, `S`, `D`, `Space`, arrow keys, `Enter`, and `F1`–`F12`.
- Automatically detect running Roblox processes.
- Check whether AutoHotkey v2, Python, and pywinauto are available.
- Install or upgrade pywinauto from the application.
- System tray integration.
- Graceful worker shutdown with a stop flag and forced termination fallback.
- Emergency stop shortcut in AutoHotkey mode: `Ctrl + Alt + Q`.

## Requirements

- Windows 10 or later is recommended.
- [Node.js](https://nodejs.org/) and npm.
- Rust and Cargo.
- [AutoHotkey v2](https://www.autohotkey.com/) for AutoHotkey mode.
- Python 3 and `pywinauto` for Python / pywinauto mode.

The application checks the required runtime dependencies when it starts. If Python is installed but pywinauto is missing, the application provides an installation button.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/neil289506-commits/RobloxAFK.git
cd RobloxAFK
```

### 2. Install JavaScript dependencies

```bash
npm install
```

### 3. Install the Rust toolchain

Install Rust through [rustup](https://rustup.rs/) if it is not already available, then verify the installation:

```bash
rustc --version
cargo --version
```

### 4. Install optional runtime dependencies

For AutoHotkey mode, install AutoHotkey v2. For example, with Windows Package Manager:

```powershell
winget install AutoHotkey.AutoHotkey
```

For Python / pywinauto mode, install Python 3 and ensure it is available on your `PATH`. The application can install pywinauto automatically, or it can be installed manually:

```powershell
python -m pip install --upgrade pywinauto
```

## Development

Start the Tauri development application with:

```bash
npm run dev
```

The frontend is located in `src/index.html`, while the native Tauri/Rust implementation is located in `src-tauri/src/main.rs`.

## Building

Create a production build with:

```bash
npm run build
```

The Tauri configuration is set up to create a Windows NSIS installer. Build output is generated by Tauri in its standard release directories.

## Usage

1. Launch Roblox and open the game where you want to remain active.
2. Start Roblox AFK.
3. Confirm that the environment checks pass.
4. Select an automation mode:
   - Use **AutoHotkey** when Roblox can remain focused.
   - Use **Python / pywinauto** when you need background window messages.
5. Choose a key and action type:
   - **Hold** keeps the key pressed for the configured duration.
   - **Tap** presses the key one or more times.
6. Set the interval between action cycles.
7. For Python / pywinauto mode, enter the Roblox process ID or use automatic detection.
8. Click **Start**.
9. Click **Stop** when the automation is no longer needed.

The application minimizes or hides itself while the worker is active and can be restored from the system tray.

## Troubleshooting

### AutoHotkey is not detected

Make sure AutoHotkey **v2** is installed. AutoHotkey v1 is not supported by the bundled script.

### pywinauto is not detected

Make sure Python 3 is installed and available on `PATH`, then use the in-app installation button or run:

```powershell
python -m pip install --upgrade pywinauto
```

### Roblox cannot be found

Open Roblox before starting the worker. In Python / pywinauto mode, verify that the selected process ID belongs to the visible Roblox window.

### The background mode does not work

Some Roblox windows or experiences may not respond to background `PostMessage` keyboard input. In that case, try AutoHotkey mode and keep Roblox in the foreground.
